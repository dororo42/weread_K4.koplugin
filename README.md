在 KOReader 上阅读微信读书书籍和公众号文章、同步阅读时长的插件。

## 项目来源

本分支 fork 自 [finlater/weread.koplugin](https://github.com/finlater/weread.koplugin)（AGPL-3.0）。
- 基线：官方 **v0.6.0**（含个人 K4 适配补丁）
- 上游最新：**v1.0.0**（本分支**不跟随**，见「与主线 v1.0.0 的差别」）

## 本分支定位

面向 **Kindle 4（非触摸）** 等无触摸屏设备：
- 全交互按键可操作（方向键 + 确认 + 返回 + 键盘数字行），无触摸手势依赖
- 离线优先：手动登录（USB 模板导入）、离线阅读时长上报、离线缓存阅读
- 精简功能面：去掉触摸设备才用得到的划线/想法、书评等

## 安装

1. 将 `weread.koplugin` 文件夹复制到 KOReader 的 `plugins` 目录：
   ```
   koreader/plugins/weread.koplugin/
   ```
2. 重启 KOReader，在菜单中找到 `工具 → 微信读书`。

> 建议 KOReader 2026.03 或更高版本。

## 键盘操作速查

Kindle 4（K4）没有物理键盘，实体键只有：5 向 D-pad、左右翻页键、Home/Back/Menu/Keyboard 按钮。

- **菜单/列表**：方向键移动、中央键确认、返回退出（KOReader 原生支持）
- **阅读统计**：
  - 中央键（Press）循环切换 周/月/年/总
  - 左/右 翻上一/下一周期
  - 上/下 或 左右翻页键 滚动页面
  - 返回 关闭
  - 数字键 1/2/3/4 直接切 Tab 仅对带实体键盘的机型有效（Kindle Keyboard：Alt+Q/W/E/R）
- **搜索/验证码**：Keyboard 按钮调出屏幕虚拟键盘输入
- **手动登录**：无需键盘——USB 连接后编辑 `koreader/settings/weread_manual_login.lua` 模板文件，重启或「立即导入」
- **快捷菜单**（可选）：插件通过 KOReader Dispatcher 暴露三个动作，可在 `工具 → 更多工具 → 手势与快捷键管理`（Dispatcher）里绑到某个实体键：
  - `WeRead · 快捷菜单`（`weread_quick_menu`）——阅读中一键调出书架/搜索/目录/下一章/同步进度/关闭书籍的快捷面板
  - `WeRead · 同步阅读进度`（`weread_sync_progress`）
  - `WeRead · 书架`（`weread_bookshelf`）
  - 未绑定时，这些功能仍可从 `工具 → 微信读书` 菜单进入（阅读微信读书缓存书籍时菜单会插入「立即同步进度」「书籍详情」）。

├── 书架
├── 搜索
├── 阅读时间上报
│   ├── 启用阅读时间上报

│   └── 上报状态
├── 阅读统计
├── 设置
│   ├── 缓存管理（扫描并关联本地书籍 / 缓存清理 / 缓存目录）
│   ├── 进度管理（打开时拉取进度 / 关闭时上传进度）
│   ├── 下载设置（书籍图片 / 公众号文章图片 / 章节预下载：自动预下载下一章、显示预下载提示）

## 登录

插件只支持微信扫码登录（K4 上扫码不便时请使用菜单 `设置 → 账号管理 → 手动登录` 的 USB 模板方式）。
扫码前需在微信读书 App 中开通微信读书 Skill 并获取 API Key。

## 阅读时长上报

> **默认关闭**：阅读时长上报功能默认不启用，需手动开启，否则阅读时间不会同步到微信读书。

开启步骤：
1. `工具 → 微信读书 → 阅读时间上报 → 启用阅读时间上报`
2. `选择目标书籍`——「自动关联」会跟随当前打开的微信读书书籍；「手动设置」则固定上报某本书
3. （可选）`仅在阅读时上报`：关闭后即使未打开书籍也会按设定目标后台累计

上报状态查看：`阅读时间上报 → 上报状态`，可看到运行状态、已上报次数、最后上报时间，以及离线积压的待补报分钟数（联网后会自动以小包分批补报）。
